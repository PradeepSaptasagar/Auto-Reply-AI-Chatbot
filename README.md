# Auto Reply AI Chatbot 🤖

### Context-Aware AI Reply Generation

An AI-powered desktop application that generates context-aware replies to messages using an LLM and desktop automation.

The project explores how an AI model can be connected directly to an existing user workflow.

## Workflow

```text
Incoming Message
       ↓
Capture Context
       ↓
Prompt Construction
       ↓
LLM
       ↓
Generated Reply
       ↓
Desktop Automation
       ↓
Send Response
```

## Technology

* Python
* Groq LLM API
* PyAutoGUI
* Pyperclip
* Prompt Engineering

## Engineering Focus

* LLM API integration
* Prompt construction
* Context-aware generation
* Clipboard automation
* Desktop interaction
* Workflow automation

## Key Idea

Instead of building another standalone chatbot interface, this project experiments with embedding AI into an existing desktop communication workflow.
